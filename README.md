# SmartStock Manager

AI-powered inventory and order management system built with Python, SQLite, Streamlit, and machine learning forecasting.

## Features

- Inventory tracking
- Order management
- Low-stock alerts
- Revenue analytics
- AI demand forecasting
- Interactive dashboards and charts
